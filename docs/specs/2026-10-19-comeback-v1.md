# comeback v1 spec

Date: 2026-10-19. Status: draft for approval.

## Problem

Reporting a UI bug to a coding agent takes a screenshot, a paste, and a typed explanation, and it loses the sequence: what was clicked, what moved, what was pointed at while talking. comeback records the screen, the microphone, clicks and drawn ink, and compiles them into a small bundle an agent can read cheaply. A "comeback" is a dish a guest sends back to the kitchen because something is wrong.

Concepts come from kitlangton/scrawl (MIT, macOS only). comeback is a clean Rust reimplementation for Linux with no Scrawl code copied. If any is ported later, its MIT notice goes in `THIRD_PARTY.md`.

## Settled decisions

| Decision | Choice | Basis |
|---|---|---|
| Name | `comeback` (crate, binary, repo `escoffier-labs/comeback`) | Free on crates.io and GitHub, 2026-10-19 |
| Language | Rust | User preference |
| Platforms | Linux first, X11 and Wayland both in v1. Windows after v1 | User choice |
| Delivery | Clipboard text plus an agent skill. No session routing | User choice |
| v1 extras | Ink marks, `zoom`/`frames`, dev-page SDK, mp4 export | User choice |
| Media pipeline | GStreamer via `gstreamer-rs` | One clock for video and audio. `ximagesrc` on X11 and `pipewiresrc` on Wayland feed the same pipeline |
| Transcription | `whisper-rs` (whisper.cpp), `cuda` cargo feature optional, default model `small.en` | Local, word timestamps, single binary, portable to Windows |
| UI | Tray icon (`ksni`, StatusNotifierItem) plus desktop notifications. No review window | YAGNI. The bundle is the review artifact |
| License | MIT, Solomon Neas | Matches other Escoffier repos |

Decisions in the last four rows were made by the implementer without a user question and can be overridden before planning.

## User flow

1. `comeback daemon` runs at login (systemd user unit). Tray icon shows idle.
2. Tap Alt+Shift+S: recording starts on the monitor under the pointer. Tray icon turns red, a notification says "Recording".
3. Talk, click around. On X11, hold Shift and drag to draw red ink. On Wayland, press Alt+Shift+D to freeze the screen and draw, then press it again (or Esc) to resume.
4. Tap Alt+Shift+S again: recording stops, the bundle compiles (target under 10 s for a 60 s capture on a recent desktop), and the clipboard gets the paste text. A notification says "Copied".
5. Paste into Claude Code, Codex, OpenCode or T3. The `comeback` skill tells the agent how to read it.

Cancel and discard with `comeback cancel` or the tray menu. On X11, Esc also cancels (grabbed only while recording). Hold Alt+Shift+S for a target picker is out of scope for v1. `comeback record --window` and `--area` cover it from the CLI.

## Architecture

Cargo workspace, three crates:

```
comeback-core      platform-free: bundle model, timeline, keyframe selection,
                   summary text, contact sheet, zoom sheet. Pure functions over data.
comeback-capture   platform code behind traits: recorder, input events, hotkey,
                   ink overlay, clipboard. Backends: x11, wayland (windows later).
comeback (bin)     CLI, daemon, IPC socket, dev-page HTTP endpoint, whisper.
```

`comeback-core` must compile and pass its tests on any OS with no system libraries beyond `image`. That crate is what carries over to Windows.

### Backend selection

At daemon start: `WAYLAND_DISPLAY` set means the Wayland backend, else `DISPLAY` set means X11, else exit with an error. `COMEBACK_BACKEND=x11|wayland` overrides.

### Capture backends

| Concern | X11 | Wayland |
|---|---|---|
| Video | `ximagesrc` of the target monitor rect | xdg-desktop-portal ScreenCast via `ashpd`, `pipewiresrc` on the returned node. `restore_token` persisted so the prompt appears once |
| Mic | `pipewiresrc` or `pulsesrc` default source | same |
| Hotkey | `XGrabKey` via `x11rb` | GlobalShortcuts portal via `ashpd` |
| Hotkey fallback | `comeback toggle` (IPC), bindable as a GNOME custom shortcut | same. This is the documented fallback when the portal is missing |
| Clicks and drags | XInput2 raw button and motion events via `x11rb`, no root needed | Not available. Timeline has no global clicks. Keyframes come from ink, scene changes and speech cues |
| Ink | Override-redirect ARGB window over the target monitor, input shape empty (click-through). While Shift is held, the input shape covers the monitor and the pointer draws | Freeze-and-draw: Alt+Shift+D (a second GlobalShortcuts binding, because Wayland hides bare modifier state from other apps) shows a fullscreen window holding the last frame. Draw on it, then Alt+Shift+D or Esc to resume |
| Clipboard | `arboard` | `arboard` with `wayland-data-control`, falling back to `wl-copy` on GNOME (no data-control protocol) |

Ink strokes render with `tiny-skia`. Because the overlay or freeze window is on screen, ink is captured in the video itself, so keyframes and exports show it with no compositing step. Strokes stay visible 3 s after the last stroke, then fade over 0.5 s. Vector strokes are also stored in the manifest.

### Recording pipeline

One GStreamer pipeline per capture:

- video source, then `tee`:
  - branch 1: encode H.264 (`nvh264enc` when present, else `x264enc` `speed-preset=veryfast`) into `recording.mp4`, 30 fps cap
  - branch 2: scale to 480 px long edge, 4 fps, `appsink` into a `CandidateBuffer` (luma grid per frame plus the small RGB frame), capped at 256 MB, halving its rate when full and never dropping frames within 200 ms of a click or stroke
- mic source: resample to 16 kHz mono and write `audio.wav`. Also muxed into `recording.mp4`

All timestamps are milliseconds since capture start on the pipeline clock. Input events from other threads are stamped with the same monotonic clock (`pipeline.clock().time() - base_time`).

### Compile step (on stop)

1. Finalize the pipeline (EOS, wait up to 3 s).
2. Transcribe `audio.wav` with whisper-rs, token timestamps on, words merged from tokens. Skip if the audio is silent (RMS below threshold for 95% of samples).
3. Select keyframes (below).
4. Decode the chosen keyframes from `recording.mp4` at native resolution. Fall back to candidate frames on decode failure.
5. Draw a click ripple on click keyframes, plus the `#N M:SS` badge.
6. Render `contact-sheet.png`, write `summary.md` and `comeback.json`, copy paste text to the clipboard.

A failure in transcription produces a bundle with `transcript: null` and a `Note: transcription failed (<reason>)` line rather than no bundle. A failure before the pipeline produced any video produces no bundle and an error notification.

### Keyframe selection (comeback-core)

Inputs: events (click, drag, stroke, page event), candidate frames with luma grids, words with times. Output: ordered keyframes, each with a time, a reason and its owned words.

- Cut only on real events: an ink mark group, a click or drag inside the target, a settled scene change (luma grid diff of 0.08 or more against the previous settled frame, stable for 300 ms), or a strong spoken cue ("now", "here", "look", "watch") that snaps to a transition starting between -0.3 s and +1.2 s of the word, else the frame 150 ms after it. A cue keyframe is dropped unless its frame differs by 0.03 or more from every chosen keyframe.
- Marks drawn on the same screen (under 5% of grid cells changed around their ink) share one keyframe at the last stroke. A group closes at a click, after 20 s, or after 12 strokes. Marks are never dropped.
- Budget: 6 up to 40 s, plus one per 20 s after, at most 12. Marks first, then clicks, then cues, then scene changes.
- Coverage: any stretch over 35 s or 100 words without a keyframe gets one from inside it when a candidate qualifies.
- Each keyframe owns the words from the start of the clause in progress at its anchor until the next keyframe's anchor. Clauses break at punctuation or a pause of 1.5 s or more. Words before the first keyframe belong to it.
- Zero events and zero speech: one keyframe at the midpoint.

Constants live in one `KeyframeConfig` struct with these defaults, so tuning never touches logic.

## Bundle format

Directory `~/.local/share/comeback/captures/comeback-<unix_ms>.comeback/`:

```
comeback.json        manifest, schema below
summary.md           the paste text plus file paths
contact-sheet.png    keyframes in time order, justified rows, 6 px gutters, max 1600 px long edge
frames/frame-NN.png  full-size keyframes, 1-based
recording.mp4        video with mic audio
audio.wav            16 kHz mono
```

`comeback.json` (serde, `schema: 1`):

```json
{
  "schema": 1,
  "id": "comeback-1792432139176",
  "startedAt": "2026-10-19T14:02:11Z",
  "durationMs": 33120,
  "backend": "x11",
  "target": { "kind": "screen", "rect": [0, 0, 2560, 1440], "scale": 1.0, "app": "firefox", "title": "Settings" },
  "keyframes": [{ "n": 1, "atMs": 4120, "reason": "click", "file": "frames/frame-01.png", "said": "..." }],
  "marks": [{ "id": 1, "atMs": 9800, "endMs": 11200, "bbox": [0.41, 0.2, 0.6, 0.31], "strokes": [[[0.41, 0.2, 9800], "..."]], "keyframe": 3 }],
  "events": [{ "atMs": 4100, "kind": "click", "x": 0.51, "y": 0.93, "button": "left", "label": null }],
  "page": [{ "atMs": 4110, "kind": "console.error", "url": "http://localhost:5173/", "text": "..." }],
  "transcript": { "model": "small.en", "words": [{ "w": "Command", "startMs": 4200, "endMs": 4500 }] }
}
```

Coordinates are fractions of the target rect from the top left. Window titles stay in the manifest and the first summary line only.

Paste text (clipboard and the top of `summary.md`):

```text
[comeback 0:33 · firefox "Settings" · ~/.local/share/comeback/captures/comeback-1792432139176.comeback]
- #1 (0:04) [clicked "New tab"] "Ctrl T makes a new session, but here it should make a tab."
- #2 (0:10) [marked] "This label is wrong."
- #3 (0:18) [scene changed] "And then it just jumps."
Contact sheet: <path>/contact-sheet.png
```

## CLI

| Command | Does |
|---|---|
| `comeback daemon` | Tray, hotkey, IPC socket at `$XDG_RUNTIME_DIR/comeback.sock`, dev-page endpoint |
| `comeback toggle` / `cancel` | IPC to the daemon |
| `comeback record [--window\|--area X,Y,W,H] [--duration S]` | Headless capture, no daemon needed |
| `comeback inspect <bundle\|latest> [--json]` | Print paste text or manifest |
| `comeback zoom <bundle> --at <M:SS\|seconds\|"phrase">` `[--span 2] [--frames 12]` | Dense frame sheet around a moment. Prints PNG path, cell times and nearby words. Phrase matching is case-insensitive fuzzy over transcript words |
| `comeback frames <bundle> --from <t> --to <t> [--every <ms>]` | Extract PNGs for a range |
| `comeback export <bundle> [--out file.mp4]` | Copy or remux `recording.mp4` (ink is already in the video), optional `--crop` to the marks' union box padded 10% |
| `comeback model fetch [small.en\|base.en\|large-v3-turbo]` | Download a ggml model to `~/.local/share/comeback/models`. Reuse `~/.local/share/whisper-models` when the file exists there |
| `comeback skill [--install <dir>]` | Print or install the agent skill |
| `comeback demo --out <dir>` | Synthetic bundle from generated frames and a fixed transcript, no capture hardware |
| `comeback rebuild <bundle>` | Rerun the compile step on existing media |

## Dev-page SDK

The daemon serves `http://127.0.0.1:7317/comeback.js` and accepts `POST /events`, loopback only, with `Origin` restricted to `http://localhost:*` and `http://127.0.0.1:*`. A page includes the script in dev builds only.

The script sends, batched every 500 ms with `Date.now()` stamps:

- `pointerdown` target: tag, id, up to two classes, a label (`aria-label`, `title`, `alt`, `data-testid`, else 60 chars of text). Inputs report placeholder or name only. Password fields report nothing. Typed values are never sent.
- React component name and `file:line` from the fiber `_debugSource` or the first project frame of `_debugStack`, when present.
- `console.error`, uncaught errors, unhandled rejections: message plus first project frame.
- fetch and XHR responses with status 400 or more, or network failure: method, path without query, status, duration. No bodies, headers or cookies.

The daemon keeps the last 3 minutes per page (300 events, 16 pages) and attaches events inside the capture window to the bundle, converted from wall clock to capture ms. A page `pointerdown` within 400 ms of an X11 click replaces that click's label. On Wayland, page clicks become click events themselves. Every string is truncated to 120 chars server-side.

## Agent skill

`skills/comeback/SKILL.md`, installable with `comeback skill --install ~/.claude/skills` (and the Codex and OpenCode equivalents). It explains the paste format, says to look at `contact-sheet.png` first and trust the screen over the transcript when they disagree, and documents `zoom`, `frames` and `inspect`. Off-host agents read the bundle files directly.

## Errors and edge cases

- Portal denied or missing on Wayland: notification with the reason. `comeback toggle` still works if only GlobalShortcuts is missing.
- No mic: record video only, note it in the summary.
- Second Alt+Shift+S within 400 ms of start: ignored (debounce).
- Daemon crash mid-recording: the next daemon start finds `*.comeback/.recording` markers, finalizes what the MP4 muxer wrote if playable (`mp4mux` with `fragment-duration=1000` so partial files play), else deletes it.
- Disk: captures over 30 days old are deleted daily unless `.pinned` exists. `comeback pin <bundle>` creates it.

## Testing

- `comeback-core`: unit tests on synthetic timelines for keyframe selection (budget, mark grouping, cue snapping, coverage, word ownership) and golden-file tests for `summary.md` and contact sheet layout dimensions.
- `comeback demo` runs in CI and its bundle is validated against the schema.
- X11 backend: CI integration test under Xvfb with a dummy PipeWire or `audiotestsrc`, recording 3 s, injecting clicks with XTest, asserting the manifest has the clicks and at least one keyframe.
- Wayland backend: manual checklist in `docs/testing-wayland.md` (portal prompt once, restore token reuse, freeze-and-draw, clipboard on GNOME).
- whisper: one test on a bundled 5 s WAV fixture, gated behind `--features whisper-tests` because it needs a model file.

## Build prerequisites (Ubuntu 24.04)

Assumed present: PipeWire, a GStreamer runtime, a Rust toolchain. whisper-rs reuses ggml models in `~/.local/share/whisper-models` when present.
Install before building: `libgstreamer1.0-dev libgstreamer-plugins-base1.0-dev gstreamer1.0-pipewire gstreamer1.0-plugins-good` (for `ximagesrc`), `libxcb1-dev`, `libdbus-1-dev`, `clang` (whisper-rs bindgen). CUDA toolkit only for the `cuda` feature.

## Out of scope for v1

Windows backend, macOS, iPhone mirroring, hold-to-pick target switcher, session routing and direct send, GUI review window, auto-crop, Accessibility-tree labels for clicks, live transcription, auto-zoom export, self-updating. Windows is the next spec after v1 ships.
